Assunto: API de recebimento do processo de viabilidade — Viabiliza, contrato 2.0.0

Esta comunicação substitui a de 19 de agosto de 2026. O sistema da Prefeitura é o Viabiliza (viabiliza).

O REGIN chama a URL da Prefeitura para entregar o processo. Nesta chamada não há token nem header JWT. O JWT permanece apenas quando o Viabiliza devolve o parecer à API da JUCEB.

O GET na URL de recebimento testa a conectividade e devolve o texto 3. O POST na mesma URL envia um único JSON, o schema ProcessoDeclaracao, e também responde em texto puro:

  • 3 — protocolo gravado (HTTP 200);
  • 5 — esse protocolo já foi recebido (HTTP 200);
  • 0 — protocolo ausente ou vazio (HTTP 400). Nada é gravado.

A duplicidade é o número do protocolo. Para o processo ser criado, o JSON também precisa de razaoSocial, cnaePrincipal, areaUtilizada maior que zero, logradouro, bairro e cep. Se faltar algum desses, a resposta continua 3 e o processo não é criado.

A homologação do REGIN deve apontar somente para a URL de homologação, e a produção somente para a URL de produção. O CNPJ da Prefeitura Municipal de Salvador é 13.927.801/0001-49.

A declaração inclui, com os mesmos nomes, os dados de identificação do envio: cnpjDestino, cnpjEmpresa, cnpjOrigem, codFuncao (inteiro; exemplo 103), dataGeracao (data e hora ISO 8601), nire, RAE_CALIF_ACTV, RGP_TGE_COD_TIP_TAB e RGP_VALOR. O contrato completo, com tipos e exemplo, está no Swagger publicado e no PDF anexo.

Certos da atenção, colocamo-nos à disposição para o teste de envio assim que as URLs estiverem registradas.
