Prezados Senhores,

A Secretaria Municipal de Desenvolvimento Urbano — SEDUR, por meio de sua Coordenadoria de Tecnologia da Informação — CTI, solicita o registro das URLs do sistema Viabiliza como endereço da instituição para recebimento dos processos de viabilidade locacional enviados pelo REGIN.

O contrato é o da API de integração já publicada pela JUCEB (Guia Técnico PSCS e OpenAPI de produção): o REGIN chama a URL da Prefeitura, serviço WsProSol098, envelope EnvioDto. Não há token nem header JWT nesta chamada. O JWT permanece apenas nas chamadas que o Viabiliza faz à API da JUCEB.

O teste de conectividade é GET na URL abaixo. A resposta é texto puro 3. Em seguida, o POST do processo usa a mesma URL. A resposta também é texto puro:

  • 3 — processo recebido;
  • 5 — protocolo já recebido (duplicado);
  • 0 — protocolo ausente (HTTP 400).
Ambiente URL de recebimento
Homologação https://viabiliza-hml.salvador.ba.gov.br/api_integracao/recebe
Produção https://viabiliza.salvador.ba.gov.br/api_integracao/recebe

Pedimos que a homologação do REGIN aponte somente para a URL de homologação, e a produção do REGIN somente para a URL de produção. O CNPJ da Prefeitura Municipal de Salvador, usado no envelope, é 13.927.801/0001-49.

A documentação Swagger, com os dois servidores, está em https://viabiliza-hml.salvador.ba.gov.br/api_integracao/docs (homologação) e https://viabiliza.salvador.ba.gov.br/api_integracao/docs (produção).

O endereço deste ofício substitui o informado em 19 de agosto de 2026. O sistema é o Viabiliza (viabiliza), e não viabilidade.
