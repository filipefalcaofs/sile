# PLAN 14-01 — Onda 0: Configuração de IA multi-provider (fundação da Fase 14)

> Plano da Onda 0 do AI-SPEC (Fase 14). Entrega a **tela de configuração de provedores de IA** administrável — a fundação de que todas as funções de IA (Ondas 1-3) dependem.
> Consome: `.planning/phases/14-intelig-ncia-artificial/14-AI-SPEC.md`.

## Objetivo

Administrador gerencia provedores de IA (OpenAI/Anthropic/Google e compatíveis) pela interface do console: cria, edita, ativa/desativa, define a configuração padrão por capacidade e **testa a conexão real** — com credencial criptografada e nunca reexibida. A configuração do banco alimenta o `laravel/ai` em runtime (ponte), sem deploy.

## Critério de pronto (anti-fachada)

- CRUD real de `AiConfiguration` navegável no console, sob permissão `manter-config-ia`.
- `api_key` criptografada no banco (RN-009) e **nunca** devolvida em claro — exibição mascarada; no editar, vazio = manter.
- "Testar conexão" faz **chamada HTTP real** ao provedor; sucesso/erro reais; sem chave válida falha honestamente.
- Regra "uma configuração padrão por capacidade" garantida em transação.
- Ponte runtime aplica a config do banco em `config('ai.*')`.
- Toggles `features.ia_*` (HU-014) administráveis; desligado degrada controlado.
- `composer require laravel/ai` integrado; `config/ai.php` presente.
- `composer test` verde (SQLite + @group postgis); `vendor/bin/pint --dirty` limpo; `npm run build`/typecheck verdes.
- Guardião-entrega aprovado.

## Dependências

- Nova dependência (aprovada): `laravel/ai` (Task 6).
- Reusa: Settings/Parameter (HU-014), spatie/permission, padrão CRUD do console, componentes UI (Card/Modal/Form/ConfirmDialog).

## Tasks (TDD — teste primeiro em cada uma)

### Task 1 — Schema + model `AiConfiguration`
- **Arquivos:** `database/migrations/xxxx_create_ai_configurations_table.php`, `app/Models/AiConfiguration.php`, `database/factories/AiConfigurationFactory.php`, `tests/Feature/Ai/AiConfigurationTest.php`.
- **Campos:** `name`, `provider` (enum: openai/anthropic/gemini/azure/compativel), `capability` (text/vision/embeddings — default text), `base_url` (nullable), `api_key` (texto, criptografado), `model`, `temperature` (decimal), `max_tokens` (int), `timeout_ms` (int), `active` (bool), `is_default` (bool), timestamps.
- **Model:** cast `encrypted` na `api_key`; accessor `masked_api_key` (mostra `sk-…últimos4`); método/scope `default(capability)`; `setAsDefault()` desmarca as demais da mesma capacidade em transação.
- **TDD:** teste prova (a) `api_key` gravada cifrada e lida em claro só internamente; (b) `masked_api_key` nunca expõe a chave; (c) marcar default desmarca a anterior por capacidade.
- **Verificação:** `php artisan test --filter=AiConfigurationTest`.

### Task 2 — Permissão + toggles (HU-014)
- **Arquivos:** `RolesAndPermissionsSeeder.php` (+`manter-config-ia` → administrador), `ParameterSeeder.php` (+`features.ia_ocr|classificacao|inconsistencias|resumo|parecer|explicacao|assistente`, default off, grupo `ia`), `config/sile.php` (fallbacks), testes de seeder.
- **TDD:** seeder-tests provam permissão criada e toggles registrados com default/validação.
- **Verificação:** `php artisan test --filter=ParameterSeederTest`.

### Task 3 — Contrato + teste de conexão real
- **Arquivos:** `app/Services/Ai/AiProviderClient.php` (contrato `testConnection(AiConfiguration): ConnectionResult`), `app/Services/Ai/OpenAiCompatibleClient.php` (GET `{base_url}/models` com `Authorization: Bearer`), binding no provider.
- **TDD:** `Http::fake` cobre sucesso (200 → ok), 401 (credencial inválida → erro claro), timeout/erro de rede. A ação real no app usa HTTP real.
- **Verificação:** `php artisan test --filter=AiProviderClientTest`.

### Task 4 — CRUD backend + autorização
- **Arquivos:** `app/Http/Controllers/Gestao/AiConfigurationController.php` (index/store/update/destroy/test/toggleActivation), `StoreAiConfigurationRequest`, `UpdateAiConfigurationRequest` (api_key `nullable` no update = manter), rotas `routes/gestao.php` sob `can:manter-config-ia`, auditoria RN-002.
- **TDD:** CRUD + autorização (403 sem permissão) + máscara na resposta + "uma padrão" + `test` retorna resultado real (Http::fake).
- **Verificação:** `php artisan test --filter=AiConfigurationControllerTest`.

### Task 5 — UI React (espelha os screenshots)
- **Arquivos:** `resources/js/pages/gestao/config-ia/index.tsx` (grid de cards: PADRÃO/Ativa, modelo, URL, chave mascarada, ações Testar/Editar/Excluir + "Nova Configuração"), modais criar/editar (Provedor + Parâmetros, checkboxes Ativa/Padrão), ação Testar com feedback real, ConfirmDialog no excluir; item na navegação do console (gated).
- **Verificação:** `npm run build` + typecheck; smoke navegável.

### Task 6 — Integração `laravel/ai` + ponte runtime + fechamento
- **Arquivos:** `composer require laravel/ai`; `config/ai.php`; `app/Providers/AiConfigServiceProvider.php` (aplica config do banco em `config('ai.*')` no boot); `database/seeders/AiConfigDevSeeder.php` (exemplo dev, sem chave real exposta); navegação.
- **Verificação:** `composer test` (2 processos), `vendor/bin/pint --dirty`, `npm run build`; guardião-entrega.
