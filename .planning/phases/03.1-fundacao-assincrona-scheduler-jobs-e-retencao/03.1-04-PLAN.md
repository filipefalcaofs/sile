Provar `tentativas = retries + 1` por EXAUSTÃO DE SEQUÊNCIA, espelhando aquele teste: empilhar (retries+1) falhas + 1 sucesso; a 1ª chamada esgota exatamente as falhas e lança, a 2ª encontra o sucesso. Logo, asserir "1ª lança / 2ª sucede" com exatamente (retries+1) falhas comprova o número de tentativas governado pelo parâmetro.

    ```php
    // retries=1 → 2 tentativas por lookup. Empilha 2 falhas + 1 sucesso:
    // 1ª chamada esgota as 2 falhas (lança); 2ª chamada encontra o sucesso.

    } catch (CnpjLookupException) {
        // esperado — número de tentativas seguiu o parâmetro
    }

    $data = $service->lookup('00000000000191');
    $this->assertSame('BANCO DO BRASIL SA', $data->legalName);
    ```
