<objective>
O **motor de classificação de risco** — coração da fase. Espelha `TerritoryService`: recebe `RiscoInput` (CNAE + respostas de condicionante + contexto de gatilhos + data), resolve as versões vigentes (ou da época) das dimensões municipal e sanitária, aplica a reclassificação por condicionante-pergunta, determina o **encaminhamento** pela dimensão decisiva via mapa parametrizado, aplica os **gatilhos** (semi-expresso → análise) e devolve `RiscoResult` com fundamentação e versões — tudo auditado (RN-002).

Purpose: HU-047 (classificar, 2 dimensões separadas), HU-048 (baixo + condicionantes atendidas = expresso), HU-049 (encaminhamento parametrizável + gatilhos), HU-050 (alto → análise), HU-051 (exceção ZEIS via gatilho). É a DECISÃO DE ROTEAMENTO auditada — não o processo expresso (Fases 8/9): sem fachada.
Output: `RiscoClassificationService` com `classify(RiscoInput): RiscoResult`, coberto por feature tests cobrindo cada CA das HUs.
</objective>

    Resolução de versão (espelha TerritoryService::resolveLayer): para cada domínio (RiscoMunicipal, RiscoSanitario), `RuleVersion::vigente($domain)->first()` (ou `naData($domain, $input->data)` quando data informada). Toda lookup de classificação/condicionante é escopada por `rule_version_id` da versão resolvida — reprodução por época (RN-005).

    Dimensão MUNICIPAL: buscar RiskClassification por (rule_version_id, cnae_code). Ausente → status 'nao_classificado' (sem nível). Presente → nivel + condicionantes_gerais + versao_regras.

    Dimensão SANITÁRIA (SEPARADA): buscar SanitaryRiskClassification por (rule_version_id, cnae_code). Ausente → 'nao_classificado'. Presente → nivel_original. Buscar RiskCondicionante do CNAE; para cada uma com regra_reclassificacao e resposta correspondente em `$input->respostasCondicionantes`: se resposta == regra_reclassificacao['resposta_gatilho'] → nivel_final = regra_reclassificacao['reclassifica_para'] e reclassificado=true; senão nivel_final = nivel_original. Registrar as perguntas/respostas no resultado.

    ENCAMINHAMENTO (parametrizado): dimensão decisiva = `Settings::get('risco.dimensao_tvl','municipal')`. Nível decisivo = nivel da dimensão decisiva (sanitário usa nivel_final pós-reclassificação). Mapa = `Settings::get('risco.mapa_encaminhamento', [...])`. fluxo = mapa[nivel_decisivo] ?? 'analise' (chave ausente = análise, FA-02 seguro). dimensao_decisiva e motivo no resultado.

    GATILHOS (HU-049/HU-051): carregar RiskTrigger::ativos(); para cada gatilho cujo codigo está em `$input->gatilhosContexto` → forçar fluxo 'analise', acrescentar a gatilhos_acionados[] com {codigo, motivo}. Gatilho derruba expresso para análise mesmo em baixo risco (semi-expresso). ZEIS especial (HU-051) é o gatilho 'zeis_especial' alimentado pelo contexto (território da Fase 4 — wiring real é EP07; aqui o motor APLICA a regra sobre o contexto recebido, sem simular território).

    CNAE não classificado na dimensão decisiva → fluxo 'analise', motivo 'Classificação de risco não parametrizada para o CNAE' (FA-02, CA-03 — decisão automática bloqueada, segue para tratamento).
