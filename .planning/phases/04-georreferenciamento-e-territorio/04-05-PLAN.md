    - `nearestFeature(GeoLayer $layer, float $lng, float $lat, int $maxMeters): ?array` (via mais próxima dentro de N metros).
    - `intersectingFeatures(GeoLayer $layer, float $lng, float $lat): array` (todas que interceptam — para restrições).

    Criar `app/Services/Geo/PostgisSpatialRepository.php implements SpatialRepository` com SQL real (DB::raw, sempre filtrando `geo_layer_id = $layer->id`):
    - containingFeature:
    ```php
    DB::table('geo_features')->where('geo_layer_id', $layer->id)
        ->whereRaw('ST_Contains(geometry, ST_SetSRID(ST_MakePoint(?, ?), 4326))', [$lng, $lat])
        ->selectRaw('id, properties')->first();
    ```
    - nearestFeature (METROS via ::geography — Pitfall 4):
    ```php
    DB::table('geo_features')->where('geo_layer_id', $layer->id)
        ->whereRaw('ST_DWithin(geometry::geography, ST_SetSRID(ST_MakePoint(?, ?), 4326)::geography, ?)', [$lng, $lat, $maxMeters])
        ->orderByRaw('ST_Distance(geometry::geography, ST_SetSRID(ST_MakePoint(?, ?), 4326)::geography)', [$lng, $lat])
        ->selectRaw('id, properties, ST_Distance(geometry::geography, ST_SetSRID(ST_MakePoint(?, ?), 4326)::geography) AS distancia_m', [$lng, $lat])
        ->first();
    ```
    - intersectingFeatures: `ST_Intersects(geometry, ST_SetSRID(ST_MakePoint(?, ?),4326))` selecionando properties.
    Decodificar `properties` (jsonb) para array no retorno.
