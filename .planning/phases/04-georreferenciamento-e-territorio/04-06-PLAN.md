      ```php
      $wkt = ...; // GeoJSON do polígono → ST_GeomFromGeoJSON
      $row = DB::selectOne(
          'SELECT ST_Area(ST_Intersection(g.geom, f.geometry)) / NULLIF(ST_Area(g.geom),0) AS ratio
             FROM geo_features f
             CROSS JOIN (SELECT ST_SetSRID(ST_GeomFromGeoJSON(:poly),4326) AS geom) g
            WHERE f.geo_layer_id = :layer AND ST_Intersects(f.geometry, g.geom)
            ORDER BY ratio DESC LIMIT 1', [...]);
      $percent = $row ? round($row->ratio * 100, 2) : 0.0;
      $alerta = $percent < $limiar;
      ```
      status = `alerta_sobreposicao` quando alerta, senão `validado`.
