<objective>
Protocolar (HU-068) — o coração da fase: dentro de UMA transação, valida os documentos obrigatórios (bloqueia se faltar), gera o número único (`ProtocolNumberGenerator` com lock + unique), transiciona rascunho→protocolada (StateMachine: timeline + auditoria), congela o snapshot de simulação e registra a ciência quando o requerente prossegue apesar da tendência. Após o commit, dispara `SolicitacaoProtocolada` — o PRIMEIRO evento de domínio do sistema — com o listener `RegistrarTrilhaProtocolo`.

Purpose: critério 3 do ROADMAP (protocolo com número único rastreável) + HU-141 RN-002/003 (não bloqueia; ciência registrada). Anti-fachada: número único de verdade (concorrência provada em @group postgis); faltar documento bloqueia com aviso; a auditoria do protocolo NÃO depende do evento (transição síncrona garante RN-002 mesmo se um listener falhar); ganchos EP09/11/13 só pendurarão listeners depois.
Output: ProtocolarSolicitacaoService + evento + listener + ProtocoloController + request + rota + feature tests (Event::fake + transição/timeline) + @group postgis (concorrência do número).
</objective>
